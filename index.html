Postman Collection Generator

กรอกข้อมูล → กด Export → ได้ไฟล์ .postman_collection.json ไปกด Import ใน Postman ได้เลย (ทำงานในเครื่องคุณ ไม่ส่งข้อมูลออกไปไหน)

1. ทั่วไป

2. OAuth 2.0 token

จะได้ request "00-Auth / Get Token" + pre-request script ที่ขอ/รีเฟรช token ให้อัตโนมัติ (Run Collection ได้เลย)

3. Pin IP (ไม่บังคับ)

ถ้าใส่ IP จะสร้างโฟลเดอร์แยกต่อ IP: ยิงไปที่ https://IP/... แล้วใส่ header Host: domain ให้ (ไม่ใช่ pin DNS จริง ดูข้อจำกัดในคำอธิบาย) ต้องปิด SSL verification ใน Postman สำหรับ collection นี้

4. Endpoints

method อื่นนอกจาก GET จะสร้างให้แต่ยังไม่มี body — ไปเติมใน Postman เอง
